Export the stateful routing metrics by default. A `StatefulSessionRouter` built without a `metricEmitter` now counts into a process-wide registry instead of the no-op emitter, so a provider that composes the documented stateful runtime (`new StatefulSessionRouter({...})`, `StatefulProviderRuntimeExecutor`) reports `apifuse_stateful_provider_routing_forward_total`, `apifuse_stateful_provider_routing_local_total`, `apifuse_stateful_provider_routing_reacquire_total` and `apifuse_stateful_provider_routing_deadline_expired_total` without wiring anything. A router given an explicit `metricEmitter` keeps using it and does not count into the registry; the session manager's and the event emitter's defaults are unchanged.

`serve()` starts a metrics listener on a separate port next to the primary listener, always on, serving only `GET /metrics` in the Prometheus text exposition format (`text/plain; version=0.0.4`) from that registry: a `# HELP` and `# TYPE` line for every name in the closed stateful metric set, then the touched series. `_total` names are counters, `_ms` names are histograms with millisecond buckets, the remaining names are gauges. Of the label input the emitters pass, only `providerId`, `operationId`, `redactedErrorCode`, `eventType`, `subjectKind`, `capacityClass`, `ledgerState` and `healthStatus` are exported; request, event, delivery, session, connection, service-account, owner-pod and generation identifiers, timestamps and numeric readings are dropped before storage, so a series never carries a per-request value or a session key.

The port is `ServeOptions.metricsPort`, else `APIFUSE__PROVIDER_RUNTIME__METRICS_PORT`, else `9090` (`DEFAULT_PROVIDER_METRICS_PORT`); `0` binds an ephemeral port. `ProviderServerHandle` gains `metricsPort`, the bound port, and `serve` logs one `provider_metrics_listener` boot event naming it. The primary listener does not serve `/metrics`, and the metrics listener serves nothing else, so the primary port's network boundary is unchanged. Processes that call `serve()` more than once (tests) must give each call its own `metricsPort`; they share the one registry.
