# Pre-lever redactor differential fixture

The three `*.ts.txt` files are verbatim `git show 19d3f674eb912318d9bc0462f867077e5c721892:<path>` snapshots of `src/runtime/diagnostic-redactor.ts`, `src/runtime/request-options.ts`, and their runtime dependency `src/errors.ts`. The test pins their Git blob IDs, loads `git show` output into a temporary directory when history is available, and otherwise loads the same pinned snapshots. No network or historical checkout is required. This directory is excluded from the package and build.

`vectors.jsonl` contains 2,000 fixed cases (517,404 bytes). Each records initial credentials, a separately compiled static inventory, subsequent registrations, input text, and the exact historical output. The test also compares outputs before registration and repeats each output after registration to exercise cache invalidation and reuse. Its SHA-256 is pinned in the test.

The starting values use the performance probe's LCG (seed `0x517cc1b7`, multiplier `1664525`, increment `1013904223`, unsigned 32-bit arithmetic) and alphabet `abcXYZ019._*- /%é𝒜\n\t"\\`, with the escape sequences representing newline, tab and backslash. For each of 2,000 values, draw a length `floor(random()*24)` and that many UTF-16 code units from the alphabet. No extra random draws occur between values.

The historical revision predates intentional short-value and residual-percent policy corrections as well as the performance levers. Therefore the comparison covers their common policy domain: credentials are at least eight characters, at most two percent-encoding rounds are used, and credentials contain no literal `%HH`. Short-value policy, numbered sentinels and decode-bound fail-closed behavior remain covered by their separate exact regression tests. This fixture does not claim equivalence across those policy changes.

Map every fourth starting value to a 16-character token in `abcXYZ019._*-`, selecting character `j` with `(original.charCodeAt(j % original.length) || index + j) % 13`. Map other values to `credential-` followed by `original.toWellFormed().replace(/%([\da-f]{2})/gi, "%q$1")`. These mappings retain the performance probe's mixed Unicode/encoding cases while making the policy constraints explicit before comparison.

Ten rotating cases (200 each) exercise raw text, JSON escaping, base64, URI-component encoding, form encoding, two-round encoding, short benign text, registration after cache priming, duplicate registration of a static credential, and overlapping request credentials with a 20-value static inventory. The ASCII subset exercises the variant fast path; the large inventories exercise trie matching. Expected outputs were generated exclusively with the historical snapshot. There are no cases skipped or tolerated mismatches.
